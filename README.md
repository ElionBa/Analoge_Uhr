# README: Analog Clock Project
This project is a simple analog clock created using HTML, CSS, and JavaScript. The clock features a modern, responsive design styled with CSS and dynamic functionality powered by JavaScript.

Features:
Circular clock face with a customizable border and background image.
Real-time updates for hour, minute, and second hands.
Smooth animations for the clock hands.
Responsive design ensuring compatibility across various screen sizes.


Technologies Used:
HTML: Structure of the clock.
CSS: Styling, including the circular shape, shadows, and positioning.
JavaScript: Logic for updating the clock hands in real time.
